# Schnapsen Adaptive AI Bot

**A collaborative AI project exploring how score-based strategy switching affects performance in the Schnapsen card game.**

Built as a university Intelligent Systems project by a two-person student team. We implemented a rule-based bot that changes its card-playing strategy at a configurable score threshold, then evaluated it against an existing opponent across 5,000 simulated games.

> **Scope and attribution:** Our team's work focuses on the adaptive bot, tournament experiments, and result analysis. The underlying Schnapsen game engine, example bots, command-line interface, and GUI come from the university-provided [Schnapsen platform](https://github.com/intelligent-systems-course/schnapsen). We do not claim authorship of that framework.

## Project overview

Schnapsen is a two-player, trick-taking card game. We investigated whether a simple change in playing style, controlled by the bot's current score, would affect its results against a pre-existing AI opponent.

Our `AdaptiveThresholdBot` uses two modes:

- **Below the threshold — passive:** Prefer a non-trump card with a low point value, preserving trump cards where possible.
- **At or above the threshold — aggressive:** Prefer high-value trump cards when available; otherwise, play the highest-value legal card.

The implementation also prioritises certain non-card moves when they are available. It uses the legal moves and score information provided by the Schnapsen game engine.

This is a **rule-based agent**, not a machine-learning model trained on game data.

## Evaluation

We tested thresholds of **15, 25, 35, 45, and 55**, playing **1,000 games per threshold** against the provided `RdeepBot` opponent. The experiment script reuses the same set of random seeds across thresholds to make the configurations more comparable.

| Score threshold | Games | Adaptive bot wins | Win rate |
| ---: | ---: | ---: | ---: |
| 15 | 1,000 | 306 | 30.6% |
| 25 | 1,000 | 291 | 29.1% |
| 35 | 1,000 | 277 | 27.7% |
| 45 | 1,000 | 266 | 26.6% |
| 55 | 1,000 | 245 | 24.5% |

**Main observation:** Threshold **15** produced the highest win rate among the configurations tested. Win rates decreased as the threshold increased in this set of experiments. The result describes this opponent and experiment setup; it does not establish that threshold 15 is optimal against every opponent.

The analysis script also calculates a one-way ANOVA and an eta-squared effect-size measure for comparing outcomes across thresholds.

## Running the experiments

**Requirements:** Python 3.10 or newer. The existing platform's setup instructions are also available in its [documentation](https://intelligent-systems-course.github.io/schnapsen/).

From the project folder, install the Schnapsen package and the analysis libraries:

```bash
python -m pip install -e .
python -m pip install pandas scipy
```

Run the tournament (this plays 5,000 games and writes `experiment_results.csv`):

```bash
python run_experiments.py
```

Analyse the results:

```bash
python analyze_results.py
```

To inspect the results without rerunning the games, use the included `experiment_results.csv` and run just the analysis script.

## Limitations and next steps

- The agent follows hand-written rules rather than learning a strategy from experience.
- Only five threshold values and one opponent configuration were evaluated.
- The results are specific to the game engine, opponent settings, and experimental conditions used.
- Future work could include testing other opponents, reversing player order, trying more thresholds, and evaluating strategies with more detailed game-state information.
